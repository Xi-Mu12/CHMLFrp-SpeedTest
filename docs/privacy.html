隐私政策

CHMLFrp-SpeedTest · 最后更新：2026 年 10 月 25 日 · 版本：1.3

概要：CHMLFrp-SpeedTest 主要在你的本机运行。作者不运营用于收集测速记录的后台，不建立遥测或用户行为分析系统。使用本机 IP 查询、账号登录或推广入口时，应用会按功能访问相应的第三方服务；本页面说明相关数据的来源、用途和去向。

一、本工具处理的信息

  • 节点延迟测速：工具会向你选择的 CHMLFrp 节点公网地址发起 TCP 连接探测，以统计延迟与丢包率。目标服务器可能看到你的来源 IP；工具不会通过该连接发送个人资料。
  • 节点列表：从 CHMLFrp 公开接口 cf-v2.uapis.cn 拉取节点名称、区域和线路能力等公开信息。请求会经过网络服务商和该接口服务器，具体日志留存以相关服务方规则为准。
  • 本机 IP 查询：使用「本机 IP」功能时，工具会访问 ip-api.com 获取当前公网 IP 的归属地、运营商和 ASN 信息；查询指定 IP 时，该 IP 会作为查询参数发送给该服务。该服务按自身隐私政策处理请求，并对免费接口设置访问频率限制。
  • 账号登录（可选）：若你使用 OAuth2/OIDC 登录，认证过程由 account-api.qzhua.net 处理。应用可能在当前运行期间读取昵称、头像、邮箱和令牌，以完成登录、获取账户资料和界面展示；登录信息不会写入作者的服务器，也不会持久化保存到应用数据库。
  • 带宽测速：为测量真实上下行吞吐，工具会在测速期间通过 CHMLFrp 开放接口临时创建一条隧道，由本地 frpc 客户端接入节点完成回环吞吐测试；无论测速成功、失败还是取消，该隧道都会在用后立即删除。工具不保留隧道配置，也不保存测速记录。
  • 本地数据与导出：主题、节点选择、测速参数等偏好保存在本机；CSV / PNG 由你通过系统保存对话框选择位置，均不会自动上传。
  • 推广入口：应用内包含一个静态推广入口。只有在你点击后，系统浏览器才会打开 fanyi.qzhua.net；应用不接入个性化广告 SDK 或跨应用跟踪。

二、本工具不做什么

  • 不集成遥测（Telemetry）、崩溃统计、数据分析或个性化广告 SDK；
  • 不收集设备标识、硬件信息、使用习惯或位置轨迹；
  • 作者不出售或建立用于共享个人信息的服务；但你主动使用 IP 查询、账号登录或第三方推广入口时，相关请求会发送给对应服务提供方；
  • 除本政策列出的功能服务和你主动打开的外部链接外，不建立额外的后台数据通道。

三、数据存储

应用配置、主题偏好、节点选择和测速参数保存在你的本机（包括前端本地存储）。账号登录信息仅在当前进程中使用，应用退出后不会作为用户数据库保存。本工具没有用于接收这些数据的作者自有服务端，不存在对应的远程数据库。卸载或删除应用数据后，本地配置可能随之移除。

四、第三方服务

工具可能访问以下服务。除特别说明外，这些服务由独立第三方运营，其数据处理以各自的服务条款和隐私政策为准：

  • cf-v2.uapis.cn — 获取 CHMLFrp 节点公开数据；
  • ip-api.com — 查询公网 IP 归属地；
  • account-api.qzhua.net — 可选的 OAuth2/OIDC 账户登录；
  • fanyi.qzhua.net — 用户主动点击推广入口后打开的外部页面。

五、未成年人保护

本工具不面向未成年人定向收集信息。未成年人应在监护人指导下使用。

六、你的选择

你可以不使用本机 IP 查询、账号登录和推广入口等可选功能，也可以在本机删除应用数据。若已使用第三方账号登录，可在认证服务方管理账号授权或联系认证服务方处理相关账号请求。

七、政策更新

若本政策发生重大变更，我们会通过应用新版本及 GitHub 仓库更新说明，并更新页面顶部的日期与版本号。更新后的内容自页面标注日期起生效。
