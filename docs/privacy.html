隐私策略

CHMLFrp-SpeedTest · 生效日期：2026 年 10 月 25 日 · 版本：1.0

概要：CHMLFrp-SpeedTest 是一款运行在你本机的桌面工具。它不收集、不上传、不存储任何个人身份信息，不含任何遥测、统计或广告代码。本页面说明工具在运行过程中会接触哪些数据，以及这些数据的去向。

一、本工具处理的信息

  • 节点延迟测速：工具会向你选择的 CHMLFrp 节点公网地址发起 TCP 连接探测，以统计延迟与丢包率。测速对象为节点公网 IP / 域名，不包含你的个人数据。
  • 节点列表：从 CHMLFrp 公开接口 cf-v2.uapis.cn 拉取节点列表（名称、区域、线路类型等公开信息）。
  • 本机 IP 查询：使用「本机 IP」功能时，工具会向第三方服务 ip-api.com 发送请求，以获取你当前的公网 IP 及其归属地、运营商、ASN 信息。该请求由 ip-api.com 按其自身隐私策略处理；免费接口有访问频率限制。
  • 账号登录（可选）：若你配置并使用 OAuth2/OIDC 登录，工具会通过轻爪统一认证（account-api.qzhua.net）获取你的昵称、头像和邮箱，仅用于应用界面展示，并只保存在你的本机，不会上传至任何其他服务器。
  • 带宽测速（功能上线后）：会通过 CHMLFrp 开放接口临时创建一条隧道用于吞吐测试，测速完成后立即删除，不会保留隧道或测速记录。
  • 结果导出：导出的 CSV / 图片由你通过系统保存对话框自选位置，仅存放在本地。

二、本工具不做什么

  • 不集成任何遥测（Telemetry）、崩溃统计、数据分析或广告 SDK；
  • 不收集设备标识、硬件信息、使用习惯或位置轨迹；
  • 不向任何第三方出售、共享或传输你的个人信息；
  • 除本节「一」中列出的第三方服务外，不与任何其他服务器通信。

三、数据存储

应用配置、主题偏好与可选的登录状态仅保存在你的本机（应用配置目录）。卸载或删除应用数据后，相关信息随之移除。本工具没有服务端，不存在远程数据库。

四、第三方服务

工具在运行中可能访问以下第三方服务，它们的数据处理受其各自隐私策略约束：

  • cf-v2.uapis.cn — CHMLFrp 节点公开数据接口；
  • ip-api.com — 公网 IP 归属地查询；
  • account-api.qzhua.net — 可选的 OAuth2/OIDC 账户登录。

五、未成年人保护

本工具不面向未成年人定向收集信息。未成年人应在监护人指导下使用。

六、策略更新

若本策略发生重大变更，我们将通过应用新版本及 GitHub 仓库更新说明告知，并更新页面顶部的生效日期与版本号。继续使用本工具即视为接受更新后的策略。
